# Compare and charts

Compare turns stored rows into a focused longitudinal view. It is intended for finding patterns and gaps, not for producing a clinical conclusion.

## Choose the comparison

Start with a patient and one or more analytes. Narrow the result with the available filters:

- Date range.
- Value or flag state.
- Source report.
- Report exclusion.
- Optional HRT anchor or cycle context.

Keep the patient filter explicit when comparing history. The same analyte name can appear for different people and should not be combined accidentally.

## Read the chart

Charts can show measured values over time, reference bands, deltas between reports, and gaps where no source result exists. Hover or select a point to connect it back to its report and metadata. A missing point is not a normal result, and a reference band is not a universal target.

## Presets and preferences

Comparison presets and chart defaults are managed in Settings. Save a useful filter combination when you repeatedly review the same analytes, then confirm the selected patient and date window before each use.

Export the filtered data when you need a portable table. Protect exported CSV files according to the sensitivity of the results.
