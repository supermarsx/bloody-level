# Dashboard

The Dashboard is the starting point after unlock. It gives you a compact view of the local vault without changing any records.

## What to look for

- Recent reports and their import state.
- Patients with available history.
- Flagged or low-confidence values that deserve review.
- Recent audit activity.

Open a report or patient from the dashboard to continue into its detail view. The navigation bar keeps the main areas available: Dashboard, Ingest, Patients, Records, Audit, Compare, Ontology, and Settings.

## Global search

Use the search control to search patients, analytes, and reports. Results are grouped by type and can be navigated without the mouse:

- Press `/` to focus search.
- Type at least two characters.
- Use `ArrowUp` and `ArrowDown` to move through results.
- Press `Enter` to open the selected result.
- Press `Escape` to close the result list.

Search is local and debounced so it remains responsive while you type.
